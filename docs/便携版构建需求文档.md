## 1. 项目背景

### 1.1 产品概述

SelfPilot 是一款基于 **Tauri 2 + Vue 3 + SQLite** 的 Windows 桌面「自学计划」任务规划应用，用于目标的制定、拆解、任务推进与打卡鼓励。当前以标准安装版（NSIS）分发，安装后数据写入 `%APPDATA%\com.selfpilot.desktop`。

### 1.2 需求动因

1. **便携诉求**：目标用户（学生/离线/安全受限环境）常需将工具放到 U 盘或共享磁盘，免安装、免注册、免系统残留；
2. **数据可控**：需要应用数据随目录移动，便于备份、迁移与多机携带；
3. **部署简化**：减少对外部依赖（如安装器、WebView2 引导）的运维成本；
4. **治理一致性**：统一便携（绿色版）与安装版的行为边界，避免路径混乱与数据不隔离。

### 1.3 目标范围

本期交付 **Windows x64 绿色版**，以 `.zip` 发布，解压即用，数据落在 exe 同级 `data/`。安装版行为保持不变。

## 2. 功能需求

### 2.1 便携模式识别

- 存在 `portable.flag` → 启用便携数据目录；
- 无 flag → 回退安装版（写入应用数据目录）。

### 2.2 数据目录计算（核心）

- 便携时 `app_dir = <exe所在目录>\data`；
- 统一由 `resolve_app_dir()` 提供，禁止绕过；
- `data/` 下自动创建 `logs/`、`webview/`。

### 2.3 关键文件落点

| 数据                   | 便携路径                             |
| ---------------------- | ------------------------------------ |
| 数据库                 | `<data>/selfpilot.db`（含 WAL/shm）  |
| 日志                   | `<data>/logs/`（按天滚动）           |
| WebView2 缓存/用户数据 | `<data>/webview/`                    |
| 恢复安全网             | `<data>/selfpilot.db.before_restore` |

### 2.4 生命周期

- 安装=解压；卸载=删除目录（无残留）；升级=覆盖 `data/` 外的文件（先备份数据）。

## 3. 非功能需求

| 类别     | 要求                                        |
| -------- | ------------------------------------------- |
| 可移动性 | 目录整体拷贝/改名后数据完整可用             |
| 隔离性   | 便携运行绝不写 `%APPDATA%`/`%LOCALAPPDATA%` |
| 兼容性   | 中文/含空格路径可解压运行                   |
| 可升级性 | 新版本覆盖升级不丢数据、自动迁移            |
| 可验证性 | 目录名版本、版本文件、exe 属性版本三处一致  |
| 性能     | 不因重定向产生额外 IO 瓶颈，冷启动 ≤ 安装版 |

## 4. 技术规格

### 4.1 平台与架构

- Windows 10/11，x64；
- WebView2 Runtime（常青）。

### 4.2 技术栈与版本

| 组件                    | 版本（约束）                            |
| ----------------------- | --------------------------------------- |
| Tauri                   | 2（Rust crate / CLI ≥ 2.1.0）           |
| Rust                    | stable（见打包方案）                    |
| Vue / Vite / TypeScript | 依 package.json（Vue3 / Vite8 / TS5.6） |
| SQLite                  | sqlx 0.8，`PRAGMA foreign_keys = ON`    |

### 4.3 运行时数据重定向设计

`portable.rs::resolve_app_dir()`：

```
current_exe 目录下存在 portable.flag？
  ├─ 是 → Ok(exe_dir.join("data"))
  └─ 否 → app.path().app_data_dir()   // 安装版行为
```

- 入口改造：`lib.rs`（DB/logs）、`backup.rs`（备份/恢复路径）全部改走 `resolve_app_dir()`；
- WebView2 用户数据：便携模式设 `WEBVIEW2_USER_DATA_FOLDER = <data>\webview`（或平台额外参数）；
- 目录创建：启动时 `create_dir_all` 确保 `data/{logs,webview}` 存在。

### 4.4 安全约束（须保持既有约定）

- CSP 严格规则不得因打包弱化（`script-src 'self'` 等，见项目约定）；
- 路径校验沿用 `validate_path_scope`；恢复操作校验 SQLite 魔术字；
- 错误信息脱敏、日志仅落本目录。

`release-portable/SelfPilot-绿色版-{version}/`（含 zip、解压目录、校验和）。

## 9. 依赖与风险

- **主风险**：便携逻辑（D1/D2）未实现前，任何绿色包都不满足数据隔离，属**阻塞项**；
- **次风险**：WebView2 用户数据默认落 APPDATA，需显式重定向（D2 内包含）；
- **缓解**：验收用例 AC-2/AC-7 作为强制门槛。
