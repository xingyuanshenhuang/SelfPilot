> 版本：v1.0
> 适用对象：开发团队 / 发版人

## 1. 打包目标

产出一份**免安装、免依赖、可移动、数据随目录携带**的绿色版应用：

| 目标 | 说明 |
| --- | --- |
| 免安装 | 绿色版以压缩包分发，解压即用，无需安装器 |
| 免依赖 | 携带运行时必要 DLL 与资源，用户机无需预装 Rust 运行时（仅需 Windows 自带 WebView2）|
| 可移动 | 可将整个目录拷贝到任意路径/U 盘运行，不写 `%APPDATA%`/`%LOCALAPPDATA%` |
| 数据随身 | 数据库、日志、缓存统一写入 exe 同级 `data/` 目录，随目录迁移 |
| 版本可识别 | 目录名、版本信息文件、可执行文件版本属性三者一致 |

**核心原则**：解压后的目录内应只读写自身 `data/` 与子目录，布局如下：

```
SelfPilot-绿色版-0.1.0/
├── SelfPilot.exe            # 主程序
├── *.dll / *.resources      # Tauri 运行时依赖与资源
├── portable.flag            # 便携模式触发器（存在即启用便携路径）
├── data/                    # 运行时数据根目录（首次运行自动创建）
│   ├── selfpilot.db         # 主数据库
│   ├── selfpilot.db-wal/shm # SQLite WAL 日志（视运行模式）
│   ├── logs/                # tracing 日志
│   └── webview/             # WebView2 用户数据/缓存（隔离）
├── 启动说明.txt             # 面向最终用户的使用说明（UTF-8 BOM）
└── check-webview2.ps1       # 环境检测脚本（UTF-8 BOM）
```

## 5. 具体打包步骤

### 5.1 前端构建
```powershell
cd D:\Desktop\SelfPilot
npm ci                 # 按 package-lock.json 精确安装（保证可复现构建）
npm run build          # 产物输出到 dist/（vue-tsc 类型检查 + vite build）
```

### 5.2 后端编译（release，不产安装器）
> ⚠️ **必须启用 `custom-protocol` 特性**：它是 Tauri dev/prod 的唯一开关。`tauri build` 会自动传它；直接 `cargo build --release` 时若不显式带上，会编译成 dev 模式，运行加载 `devUrl`(localhost:1420) 而不是内嵌资源，导致 `ERR_CONNECTION_REFUSED`（见 §11 风险与缓解）。
```powershell
cd src-tauri
cargo build --release --package self-study-planner --features tauri/custom-protocol
```
产物定位：
```powershell
# 确认实际 target 目录（三级回落）
$targetDir = $env:CARGO_TARGET_DIR
if (-not $targetDir) { $targetDir = (Select-String 'target-dir' .cargo/config.toml).Line -replace '.*"([^"]+)".*','$1' }
if (-not (Test-Path $targetDir)) { $targetDir = ".\target" }
$exe = Join-Path $targetDir "release\self-study-planner.exe"
```

### 5.3 组装绿色版目录
1. 新建临时目录 `tmp/SelfPilot-绿色版-0.1.0/`；
2. 复制 `$exe` → 目录内并**重命名为 `SelfPilot.exe`**；
3. 复制运行所需依赖（见 §6 依赖处理）；
4. 写入空的 `portable.flag`；
5. 写入 `启动说明.txt`、`check-webview2.ps1`（**均须 UTF-8 with BOM**，避免 PS 5.1 中文乱码）；
6. 校验目录内容与 §1 布局一致。

### 5.4 生成发布包
```powershell
# 方案 A：zip（推荐，跨工具兼容）
Compress-Archive -Path "tmp\SelfPilot-绿色版-0.1.0" -DestinationPath "release-portable\SelfPilot-绿色版-0.1.0.zip"
# 方案 B：7z（压缩率更高，可选）
7z a "release-portable\SelfPilot-绿色版-0.1.0.zip" "tmp\SelfPilot-绿色版-0.1.0"
```

### 5.5 一键脚本封装
将 5.1–5.4 固化为 `scripts/portable/build-portable.ps1`（**UTF-8 with BOM**），支持参数：
```powershell
.\build-portable.ps1 -Version "0.1.0" -SkipFrontend  # -SkipFrontend 复用已有 dist
```
并在 `package.json` 增加脚本：
```json
"scripts": { "build:portable": "powershell -ExecutionPolicy Bypass -File scripts/portable/build-portable.ps1" }
```

## 6. 依赖项处理方法

| 依赖类型 | 处理方式 |
| --- | --- |
| Rust / Cargo | 静态链接进 `SelfPilot.exe`；`Cargo.lock` 锁定版本保证可复现 |
| 前端资源 | `npm run build` 打入 `dist/`，由 Tauri 内嵌进可执行文件，无需外置复制 |
| Tauri 运行时 DLL / `.resources` | 打包脚本从 target 目录复制对应 `*.dll`、`*.resources` 到绿色目录 |
| Node 运行时 | 不随包，仅构建期使用 |
| WebView2 | 不随包（体积大）；用 `check-webview2.ps1` 检测并引导终端用户安装 |
| 图标 / 静态资源（public/） | 已随前端构建内嵌，不单独外置 |

## 7. 压缩与加密策略

### 7.1 压缩
- 格式：`.zip`（兼容性优先）或 `.7z`（压缩率优先）；
- 压缩时**排除**运行产生的 `data/`（仅发版不含数据）、`*.log`、临时文件。

### 7.2 加密
- **默认不加密**：绿色版以易传播为目标，内部数据由应用层 CSP 与凭据不落盘约束保护；
- 若需防拷贝，可采用 zip AES-256 口令加密发布包（口令单独走安全渠道传递）；
- 数据库本体不做全盘加密（本期不引入 `SQLCipher`），仅在需求文档中列为可选增强（K-04）。

## 8. 安装与卸载流程设计

### 8.1 安装（即「部署」）
1. 用户解压 zip 到任意目录（建议非中文/无空格路径，虽代码已兼容中文路径）；
2. 首次运行 `SelfPilot.exe`：
   - 检测 `portable.flag` → 启用便携路径；
   - 自动创建 `data/`、`data/logs/`、`data/webview/`；
   - 执行 SQLite 迁移（`sqlx migrate`）初始化数据库；
3. 可选：运行 `check-webview2.ps1` 校验 WebView2，缺失时跳转官方安装页面。

### 8.2 卸载（即「移除」）
1. 关闭应用；
2. 删除整个目录（含 `data/`）即完成卸载，**无注册表、无服务、无残留**；
3. 兜底：若用户疑有残留，检查并删除 `%APPDATA%\com.selfpilot.desktop`（旧安装版遗留，便携版不应产生）。

> 便携版刻意不写注册表/快捷方式，卸载天然干净。

## 9. 版本控制机制

| 项 | 机制 |
| --- | --- |
| 源码 | Git 仓库打 tag，`git tag v0.1.0`，tag 与发布版本一致 |
| 二进制版本属性 | 由 `Cargo.toml` version + `tauri.conf.json` version 控制，打包产物读取校验 |
| 目录命名 | `SelfPilot-绿色版-{version}/`，如 `0.1.0` |
| 内部版本清单 | 绿色目录内写入 `version.txt`（版本号 + 构建时间 + 提交 hash，供查证） |
| 数据迁移 | SQLite 迁移文件 `_sqlx_migrations` 表保证 每次升级自动迁移 |
| 升级策略（本期）| **整体替换**：用户下载新版 zip，覆盖旧目录（注意先备份 `data/`） |
| 过期校验 | 升级时口径统一，见 §10.4 可升级性测试 |

## 10. 测试验证标准

### 10.1 启动与数据隔离
- [ ] 首次运行在 exe 同级生成 `data/`，且 `%APPDATA%\com.selfpilot.desktop` **不被写入**；
- [ ] 数据库 `data/selfpilot.db` 可正常迁移与读写。

### 10.2 可移动性
- [ ] 将目录整体移动到另一磁盘路径后，数据完整、可正常读写；
- [ ] 冷启动（重启系统）后运行正常。

### 10.3 安装版兼容（回归）
- [ ] 移除 `portable.flag` 后，程序回退到安装版行为（写 Roaming），不影响便携版使用。

### 10.4 可升级性
- [ ] 用新版本覆盖旧目录后：数据不丢失、迁移成功、功能正常。

### 10.5 空环境（干净机器）
- [ ] 在无开发工具、无 Rust/Node 的虚拟机上解压即可运行。

### 10.6 安全与健壮性
- [ ] CSP 生效（严格规则不被破坏）；
- [ ] 中文路径解压运行正常（SQLite 以 `filename()` 直连规避 URL 解析问题，见项目约定）。

## 11. 风险与缓解

| 风险 | 缓解 |
| --- | --- |
| 便携模式未实现导致数据落 Roaming | 将 portable.rs 列为**前置阻塞项**，验收前置 |
| WebView2 用户数据落 Roaming | 便携模式显式设置 `WEBVIEW2_USER_DATA_FOLDER` 指向 `data/webview` |
| 用户覆盖升级误删数据 | `启动说明.txt` 与 `check-webview2.ps1` 明确告知先备份 `data/` |
| target-dir 重定向导致找错产物 | 打包脚本按环境变量→config.toml→默认 三级定位并二次校验 |
| 直接 `cargo build --release` 缺少 custom-protocol，产物走 devUrl(localhost:1420) 报 `ERR_CONNECTION_REFUSED` | 脚本后端编译显式加 `--features tauri/custom-protocol`（与 `tauri build` 自动行为一致）；此项已于 2026-09-08 实测修复 |
